# 🎮 PlayFísica

**Programar para compreender: Jogos Digitais no Ensino de Física**

---

## 📘 Sobre o Projeto

O **PlayFísica** é um projeto que integra o **ensino de Física** com a **programação de jogos digitais**, utilizando a biblioteca **p5.js**.  
A proposta busca tornar a aprendizagem mais significativa, prática e motivadora, conectando os conteúdos escolares à cultura digital dos estudantes.

Por meio da criação de jogos, os alunos aplicam conceitos de Física como:

- ⚡ Força  
- 🚀 Movimento  
- 🎯 Colisões  
- 🌀 Atrito  
- 🌍 Gravidade  

Ao mesmo tempo em que desenvolvem **pensamento lógico**, **criatividade** e **habilidades em programação**.
